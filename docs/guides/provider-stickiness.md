# 会话粘性与 API 提供商绑定审计

「路由 → 会话粘性」中的「同一会话优先复用 API 提供商」默认开启；缺少该字段的旧配置也沿用开启状态，已明确保存的关闭设置会保留。闲置过期时间默认为 60 分钟，可设置 1–1440 分钟，每次请求成功后重新计时。修改后点击「保存默认策略」生效。

新工作区的「恢复与重试 → API 提供商切换」也默认开启；已有工作区保留保存的开关值。

## 选择与故障恢复

会话识别直接沿用 `convo` 和请求记录的结果，包括显式会话标识、回传的工具/响应标识和助手文本指纹。无需开启对话正文捕获，也无需让客户端额外提供粘性参数。

绑定按会话、本地访问令牌、协议族、请求模型分别隔离；Responses 和 Responses Compact 共用协议族。支持已有会话识别的 Chat、Responses、Anthropic Messages 和 Gemini GenerateContent，模型目录和旧式 Completions 不建立普通绑定。

成功请求会记住实际完成请求的 API 提供商。后续请求在当前可用候选中优先选择它，其余候选保持原有顺序。停用、不支持本次模型或协议、熔断等情况仍由原路由和执行策略处理；隐私、限流和故障转移规则继续生效。失败与已取消请求不会更新绑定。关闭自动切换仍允许优先选择已绑定的 API 提供商，但失败后不尝试其他 API 提供商。

依赖 `previous_response_id` 的 Responses 续接和已建立的 WebSocket 连接继续遵守协议绑定，优先于普通会话偏好。

## 查看与解除

进入「请求记录 → 会话详情 → API 提供商绑定」：

- 当前偏好显示 API 提供商、模型、协议和有效时间；同一会话可以有多个独立的绑定范围。
- 绑定记录展示复用、未命中、协议固定、建立、切换和手动解除，以及会话识别依据。可跳转到对应请求。
- 每页显示 100 条，支持加载更早记录。阅读历史时暂停实时刷新，点击刷新回到最新记录。
- 点击「重新选择 API 提供商」一次清除本会话的全部普通偏好，保留请求和绑定历史。下一次仍可能选中同一家。

解除不需要逐条选模型或确认弹窗，不会中断正在执行的请求。解除前已开始的请求即使稍后成功，也不能恢复已解除的绑定；解除后新请求成功可自动建立新绑定。协议固定的续接与 WebSocket 连接不受这个操作影响。

## 存储与兼容

绑定和审计保存在本地 SQLite，重启后仍可读取。最多保留 10,000 个绑定、50,000 条绑定事件；超出容量时淘汰旧数据。审计只记录本地资源标识、时间、动作和原因，不另存对话正文或原始协议游标。数据库不可用时退回正常选路。

界面和产品文案统一使用「API 提供商」（英文 API provider）。已有 API 字段与资源路径保持兼容：设置字段为 `channel_stickiness`，审计/解除端点为 `/control/v1/request-sessions/{session_id}/channel-bindings`。GET 的可选 `before` 参数是上一页末尾事件 ID，DELETE 解除普通偏好；均受控制接口鉴权保护。

## UI/UX 与验证

复用现有 Panel、Field、Switch、Button、EmptyState 和状态组件。入口放在已有会话详情内；默认自动建立绑定，用户只在排查问题时查看或解除。设置关闭时隐藏过期时间输入，错误时保留已有信息并提供重试。

绑定正文在标签面板内部滚动，页头和导航不随长历史收缩。使用实际 AppShell、macOS 标题栏间距和模拟数据，在后台内置浏览器检查：

| 视口 | 绑定内容区高度 | 横向溢出 |
| --- | ---: | --- |
| 1280 × 720 | 538 px | 无 |
| 1024 × 600 | 418 px | 无 |
| 640 × 600 | 394 px | 无 |

内容区均超过可用工作区高度的 60%。长历史滚动 2,860 px 后切换标签，文档滚动位置和页头位置保持不变；解除后的空状态、历史保留、设置折叠/展开均已检查。核心集成测试覆盖现有指纹会话识别、成功后绑定、失败不写入、关闭故障转移、解除、严格续接、过期、令牌隔离、重启、乱序完成和分页；桌面测试覆盖解除失败及分页与刷新竞争。
